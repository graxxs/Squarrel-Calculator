# «Squarrel» Calculator

## RU Русский
Веб-приложение для вычисления корней заданной степени из целых, рациональных и комплексных чисел. Работает в браузере, без установки и регистрации.

Поддерживает арифметические корни (включая нуль), комплексные корни для отрицательных чисел и режим длинных чисел с настраиваемой точностью.
Интерфейс переведён на русский, английский и французский.

Сервер: Python + Flask, клиент: HTML, CSS (Bootstrap) и немного JavaScript. Развёрнуто на RelaxDev, код на GitHub.

## EN English
A web application for calculating roots of a given degree from integers, rational numbers, and complex numbers. It runs in the browser without requiring installation or registration.

It supports arithmetic roots (including zero), complex roots for negative numbers, and a high-precision mode for large numbers.
The interface is available in Russian, English, and French.

The server uses Python and Flask; the client uses HTML, CSS (Bootstrap), and some JavaScript. It is deployed on RelaxDev, and the code is hosted on GitHub.

## FR Français

Une application web pour calculer des racines d'un degré donné à partir de nombres entiers, rationnels et complexes. Elle fonctionne directement dans le navigateur, sans installation ni inscription.

Elle prend en charge les racines arithmétiques (y compris pour zéro), les racines complexes pour les nombres négatifs ainsi qu'un mode de calcul en précision arbitraire (nombres de grande taille).
L'interface est disponible en russe, en anglais et en français.

Côté serveur: Python et Flask; côté client: HTML, CSS (Bootstrap) et un peu de JavaScript. Hébergée sur RelaxDev, code source disponible sur GitHub.
